# lokal16_software

This is a program created to help logging attendence of members.

The prodject was created using Flutter and Dart. The main source code can be found in the "lib" folder.

The program was designed to be synced to a google sheet, and might therefor not be fully fuctional without a connected spreadsheet. 
To connect the program to a spreadsheet, a Google service account key is needed. 
The key is not included in this repo due to security risks.
